Compact REST endpoints for WooCommerce product cards and a configurable, server-driven Flutter home page.

== Endpoints ==

* GET /wp-json/app-api/v1/products
* GET /wp-json/app-api/v1/products/{id}
* GET /wp-json/app-api/v1/home

See docs/API.md for parameters and examples.
