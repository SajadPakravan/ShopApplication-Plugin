# Application API v2.3.0

Base namespace:

`/wp-json/app-api/v1`

## Endpoints

- Home: `/home` by default. The Home endpoint name remains configurable in the Home settings tab.
- Product list: `/products` (fixed).
- Product detail: `/products/{id}` (fixed).

## Product list query parameters

`GET /products` supports:

- `page`
- `per_page`
- `search`
- `category` — one ID or comma-separated IDs
- `brand` — one ID or comma-separated IDs
- `min_price`
- `max_price`
- `orderby`
- `order`

`on_sale` also remains supported for product-list navigation generated by Home `view_all` actions.

The response contains:

- `pagination`
- `filters`
  - `category`: hierarchical product-category tree with nested `children`
  - `brand`: alphabetical brand list
  - `attribute`: global WooCommerce attributes whose archives are enabled, with terms/options and a color code when available
- `filter_by`: the currently applied search/category/brand/price/sort values
- `data`: lightweight product cards

`filter_by` has a stable shape:

```json
{
  "search": null,
  "category": [],
  "brand": [],
  "min_price": null,
  "max_price": null,
  "orderby": "date",
  "order": "desc"
}
```

## Home section types

The visual Home builder supports:

- `image`
- `products`
- `category`
- `brand`
- `posts`

Every section has an administrator-defined section ID, title/subtitle and this compact layout contract:

```json
{
  "direction": "horizontal",
  "rows": 1,
  "columns": 1
}
```

Rows and columns always have a minimum value of 1.

### Posts section

A `posts` section can select one or more WordPress post-category IDs and a `per_page` value. Posts are returned newest first. Each post card is lightweight:

```json
{
  "id": 123,
  "title": "Article title",
  "excerpt": "...",
  "image": "https://example.com/original-image.webp",
  "date": "2026-08-08T08:00:00+00:00"
}
```

## View all

`products`, `category`, `brand`, and `posts` sections have a View All toggle.

When disabled:

```json
"view_all": {}
```

When enabled, `view_all` contains a title and the shared action contract. For `posts`, destination types are limited to post category and URL.

## Action contract

Actions appear only in image items and section-level `view_all` objects:

```json
{
  "title": "لپ‌تاپ",
  "type": "category",
  "destination_id": 55,
  "on_sale": false,
  "url": null,
  "orderby": "date",
  "order": "desc"
}
```

They are not repeated in individual product, product-category, or brand records.

## Home cache

The Home response is cached internally for 60 seconds. The TTL is fixed in the plugin and is not exposed in the administrator settings. Relevant Home configuration, product, variation, taxonomy, and post changes bump the cache version so a newly changed Home payload can be rebuilt without requiring the manager to manage the cache manually.
