# گزارش تغییرات Application API نسخه 2.2.1

## هدف نسخه

سبک‌تر و منظم‌تر شدن JSON کارت محصولات و یکسان شدن نوع داده قیمت‌ها، بدون تغییر در منطق داخلی انتخاب متغیر پیش‌فرض، انتخاب متغیر دارای بیشترین درصد تخفیف، محاسبه تخفیف، فیلتر فروش ویژه یا مرتب‌سازی موجودی.

## قیمت‌ها

تمام فیلدهای پولی محصول در خروجی عمومی اکنون عدد صحیح JSON هستند، نه رشته:

- `price`
- `regular_price`
- قیمت‌های `default_variation`
- قیمت‌های تمام اعضای `variations`

اگر قیمت در ووکامرس خالی، نامعتبر یا `null` باشد، مقدار خروجی `0` است.

برای جلوگیری از تغییر رفتار محصولات متغیر، محاسبات داخلی همچنان با مقدار اعشاری دقیق ووکامرس انجام می‌شوند و فقط هنگام ساخت JSON به عدد صحیح تبدیل می‌شوند.

## قرارداد جدید کارت محصول

کارت محصول در API لیست محصولات، لیست‌های محصولات صفحه خانه و هر بخشی که در آینده از `format_card` استفاده کند، فقط شامل این فیلدهاست:

```json
{
  "id": 2143,
  "name": "نام محصول",
  "price": 4000000,
  "regular_price": 5000000,
  "discount_percent": 20,
  "stock_quantity": 3,
  "image": "https://example.com/original.webp",
  "variation_name": "مشکی"
}
```

فیلدهای زیر از کارت محصول حذف شدند:

- `type`
- `sku`
- `on_sale`
- `average_rating`
- `rating_count`
- `review_count`
- `total_sales`
- `categories`
- `brands`
- `tags`

برای محصول ساده، `variation_name` همیشه رشته خالی `""` است و `null` برنمی‌گردد.

## API جزئیات محصول

از سطح اصلی جزئیات محصول و از تمام متغیرها، `type` و `on_sale` حذف شدند. `sku` فقط در API جزئیات و اشیای متغیر باقی مانده است.

اطلاعات کامل مخصوص صفحه محصول مانند توضیحات، گالری، ابعاد، کلاس حمل‌ونقل، امتیازها، فروش، دسته‌بندی‌ها، برندها، برچسب‌ها، ویژگی‌ها و لیست متغیرها همچنان حفظ شده‌اند.

## فیلترها و محاسبات داخلی

پارامترهای ورودی `type` و `on_sale` همچنان برای جست‌وجو، فیلتر API محصولات و ساخت بخش محصولات تخفیف‌دار در تنظیمات خانه کار می‌کنند؛ فقط از JSON پاسخ حذف شده‌اند.

منطق‌های زیر بدون تغییر حفظ شده‌اند:

- انتخاب متغیر دارای بیشترین درصد تخفیف برای کارت محصول متغیر تخفیف‌دار؛
- حفظ اولین متغیر در صورت برابری دقیق درصد تخفیف؛
- استفاده از متغیر پیش‌فرض برای محصول متغیر بدون تخفیف؛
- استفاده از متغیر پیش‌فرض در سطح اصلی API جزئیات؛
- نمایش محصولات موجود قبل از محصولات ناموجود؛
- مقدار عددی و غیر `null` برای `stock_quantity`.
