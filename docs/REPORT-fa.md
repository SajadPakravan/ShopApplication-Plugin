# گزارش تغییرات Application API نسخه 2.7.1

## پاسخ ساده‌تر احراز هویت

پاسخ موفق Login و Register دیگر آرایه‌های `user` و `auth` ندارد. فیلدهای کاربر مستقیماً داخل `data` قرار می‌گیرند و `access_token` بلافاصله بعد از `mobile` برگردانده می‌شود.

فیلدهای زیر از پاسخ عمومی حذف شدند:

- `token_type`
- `expires_in`
- `expires_at`

انقضای توکن همچنان به‌صورت داخلی در سرور مدیریت می‌شود و حذف این فیلدها فقط قرارداد JSON عمومی را ساده‌تر می‌کند.

## قالب جدید توکن

قالب قدیمی `app1.USER_ID.SECRET` حذف شد. توکن جدید با شناسه کاربر داخل براکت شروع می‌شود:

```text
[41]xxxxxxxxxxxxxxxxxxxxxxxx...
```

شناسه ابتدای توکن برای پیدا کردن سریع کاربر استفاده می‌شود و فقط هش کامل توکن در متادیتای کاربر ذخیره می‌شود.

## حداقل طول نام کاربری

در ثبت‌نام با نام کاربری، نام کاربری باید حداقل ۴ کاراکتر داشته باشد. برای مقدار کوتاه‌تر پاسخ خطای فارسی مناسب با HTTP 400 برگردانده می‌شود:

```text
نام کاربری باید حداقل ۴ کاراکتر داشته باشد.
```

این محدودیت برای ثبت‌نام جدید اعمال می‌شود و ورود حساب‌های قدیمی را محدود نمی‌کند.
