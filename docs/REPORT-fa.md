# گزارش تغییرات Application API نسخه 2.0.3

## لینک تصویر اصلی و باکیفیت

تابع مشترک تولید تصویر بازنویسی شد. اکنون تمام فیلدهای `image` در این بخش‌ها از تصویر اصلی آپلودشده استفاده می‌کنند و نه سایز تولیدشده `150x150` یا `woocommerce_thumbnail`:

- کارت محصولات در `GET /products`
- محصولات بخش‌های صفحه خانه
- تصویر سطح اصلی `GET /products/{id}`
- `default_variation`
- تمام اعضای `variations`

اولویت دریافت تصویر به این صورت است:

1. تصویر اصلی آپلودشده از `wp_get_original_image_url`
2. آدرس کامل attachment
3. سایز `full`
4. placeholder کامل ووکامرس

این fallbackها باعث می‌شوند پلاگین روی وردپرس‌های قدیمی‌تر، رسانه‌های قدیمی و افزونه‌های انتقال تصاویر به CDN نیز پایدار بماند.

## گالری محصول

به API جزئیات محصول فیلد `gallery` اضافه شد. این فیلد یک آرایه JSON از لینک تصاویر اصلی و باکیفیت است.

ترتیب تصاویر:

1. تصویر انتخاب‌شده اولیه؛ برای محصول متغیر همان تصویر متغیر پیش‌فرض
2. تصویر شاخص محصول والد، اگر تکراری نباشد
3. تصاویر ثبت‌شده در گالری ووکامرس

شناسه‌ها و لینک‌های تکراری حذف می‌شوند.

## فیلدهای جدید جزئیات محصول

این فیلدها فقط به پاسخ `GET /products/{id}` اضافه شدند:

- `description`: توضیحات کامل محصول به‌صورت HTML پالایش‌شده
- `dimensions`: شامل `length`، `width` و `height`
- `shipping_class`: نامک کلاس حمل‌ونقل ووکامرس
- `attributes`: فهرست ویژگی‌های محصول

`average_rating`، `rating_count` و `total_sales` از قبل در formatter مشترک وجود داشتند و در پاسخ جزئیات نیز باقی مانده‌اند.

ساختار هر ویژگی:

```json
{
  "name": "رنگ",
  "visible": true,
  "options": ["مشکی", "سفید"]
}
```

عبارت `visible` در درخواست دوبار نوشته شده بود؛ در خروجی فقط یک‌بار قرار می‌گیرد، چون وجود دو کلید هم‌نام در یک شیء JSON قابل اتکا نیست.
