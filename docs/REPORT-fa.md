# گزارش تغییرات اپلیکیشن فروشگاه نسخه 3.0.1

این نسخه یک بازطراحی اصلی در هویت افزونه، پنل مدیریت و معماری وب‌سرویس‌ها است.

## تغییر نام افزونه

- نام نمایشی افزونه: «اپلیکیشن فروشگاه»
- نام انگلیسی پروژه: Shop Application
- پوشه افزونه: `shop-application`
- فایل اصلی: `shop-application.php`
- آیکون منوی مدیریت: موبایل

namespace REST برای جلوگیری از شکستن نسخه‌های فعلی اپلیکیشن همچنان `app-api/v1` باقی مانده است.

## منوی مدیریت

منوی مستقل «اپلیکیشن فروشگاه» با دسترسی `manage_options` ایجاد شده و شامل زیرمنوهای زیر است:

- مدیریت اپلیکیشن
- وب‌سرویس‌ها
- تنظیمات
- ابزارها

صفحه وب‌سرویس‌ها چهار کارت ریسپانسیو دارد: مشتریان، مدیران، احراز هویت و نوتیفیکیشن. در دسکتاپ کارت‌ها دو ستونه و در موبایل تک‌ستونه هستند و در hover توضیحات کامل‌تر نمایش داده می‌شود.

## وب‌سرویس مشتریان

وب‌سرویس‌های بدون نیاز به ورود با عنوان «وب‌سرویس‌های عمومی» شامل خانه، محصولات و دسته‌بندی‌ها هستند.

وب‌سرویس‌های نیازمند حساب با عنوان «وب‌سرویس‌های حساب کاربری» نمایش داده می‌شوند و فعلاً API مشتری در آن قرار دارد.

## API مشتری

مسیر جدید:

`GET /wp-json/app-api/v1/customers/{id}`

این مسیر نیازمند Bearer Token است. مشتری فقط اطلاعات شناسه خودش را می‌تواند دریافت کند و مدیران سایت/ووکامرس امکان دسترسی مدیریتی به شناسه‌های دیگر را دارند.

خروجی شامل مشخصات فردی، شماره تماس، ایمیل، آواتار، آدرس صورتحساب، آدرس ارسال، سفارش‌ها، اقلام سفارش، سبد خرید ماندگار ووکامرس، علاقه‌مندی‌ها و دانلودهای قابل دسترس است.

برای Wishlist چون WooCommerce Core لیست علاقه‌مندی داخلی ندارد، قرارداد `wishlist` ثابت نگه داشته شده و اتصال افزونه Wishlist از طریق فیلتر `shop_application_customer_wishlist` انجام می‌شود.

## پاسخ احراز هویت

در Login و Register:

- `mobile` به `phone` تغییر کرد.
- `access_token` به `token` تغییر کرد.

ساختار توکن `[user_id]secret` و منطق امنیتی هش‌شده سمت سرور حفظ شده است.
