# گزارش تغییرات Application API 2.5.3

## اکشن آیتم‌های بخش تصویر

- قرارداد `action` آیتم‌های تصویر با قرارداد جدید مقصدها یکسان شد.
- `destination_id` از خروجی عمومی اکشن تصویر حذف شد.
- سه فیلد صریح اضافه/استفاده می‌شوند: `product_id`، `category_id` و `brand_id`.
- `product_id` فقط یک شناسه عددی می‌گیرد.
- `category_id` و `brand_id` آرایه هستند و می‌توانند یک یا چند شناسه داشته باشند.
- اگر نوع مقصد «محصول» باشد ولی شناسه محصول خالی باشد، خروجی عمومی `type = all` و `product_id = null` خواهد داشت.
- گزینه «فقط محصولات تخفیف‌دار نمایش داده شوند» برای مقصدهای محصول، دسته‌بندی و برند فعال است.
- برای مقصد دسته‌بندی و برند، وارد کردن حداقل یک شناسه در فرم مدیریت الزامی شده است.

## رابط مدیریت

عنوان فیلد مقصد بر اساس نوع انتخاب‌شده تغییر می‌کند:

- محصول → «شناسه محصولات»
- دسته‌بندی → «شناسه دسته‌بندی‌ها»
- برند → «شناسه برندها»
- لینک → «لینک مقصد»

برای مقصد محصول فقط یک شناسه قابل ثبت است. خالی گذاشتن آن به معنی همه محصولات است.

## سازگاری

تنظیمات قدیمی که از `destination_id` یا `destination` استفاده می‌کردند هنگام خواندن به ساختار جدید مهاجرت می‌شوند. اکشن‌های `view_all` نیز برای ثبات قرارداد دارای `product_id: null` هستند.
