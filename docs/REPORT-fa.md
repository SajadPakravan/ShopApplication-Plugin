# گزارش تغییرات Application API نسخه 2.0.2

## API جزئیات محصول

برای محصول متغیر دو فیلد جدید اضافه شد:

- `default_variation`: اطلاعات کامل متغیر پیش‌فرض
- `variations`: فهرست تمام متغیرهای منتشرشده، به ترتیب ثبت‌شده در ووکامرس

هر متغیر شامل این فیلدهاست:

`id`, `name`, `sku`, `price`, `regular_price`, `discount_percent`, `on_sale`, `stock_quantity`, `image`

در محصول متغیر، اطلاعات قیمت، تخفیف، تصویر و موجودی سطح اصلی پاسخ همیشه از متغیر پیش‌فرض گرفته می‌شود. اگر تنظیم متغیر پیش‌فرض ناقص یا نامعتبر باشد، اولین متغیر منتشرشده به‌عنوان fallback استفاده می‌شود.

فیلدهای `image_id` و `stock_status` از API جزئیات حذف شدند.

## API لیست محصولات

- محصول متغیرِ بدون تخفیف از قیمت، قیمت اصلی، تصویر و موجودی متغیر پیش‌فرض استفاده می‌کند.
- محصول متغیرِ تخفیف‌دار همچنان از متغیری استفاده می‌کند که بیشترین درصد تخفیف را دارد.
- در تساوی درصد تخفیف، اولین متغیر طبق ترتیب ووکامرس انتخاب می‌شود.
- `stock_quantity` دیگر در هیچ حالت `null` نیست.
- محصول ناموجود مقدار `stock_quantity: 0` دارد.
- وقتی ووکامرس موجود بودن را مشخص کرده اما تعداد دقیق را نگهداری نمی‌کند، مقدار قراردادی `1` برگردانده می‌شود.

## مرتب‌سازی موجودی

مرتب‌سازی موجودی در سطح SQL و قبل از صفحه‌بندی انجام می‌شود:

1. ابتدا تمام محصولات موجود
2. سپس تمام محصولات ناموجود یا دارای موجودی صفر
3. داخل هر گروه، مرتب‌سازی درخواستی کاربر بر اساس `orderby` و `order`

بنابراین محصولات ناموجود فقط در انتهای صفحه جاری جابه‌جا نمی‌شوند، بلکه بعد از پایان تمام محصولات موجود در کل نتیجه فیلترشده نمایش داده می‌شوند.
