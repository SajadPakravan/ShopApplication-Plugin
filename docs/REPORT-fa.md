# گزارش تغییرات Application API نسخه 2.0.4

## ساده‌سازی پاسخ API خانه

سه پارامتر اضافی از پاسخ `GET /home` حذف شدند:

- `schema_version`
- `currency`
- `generated_at`

ساختار سطح اول اکنون فقط شامل `success` و `sections` است.

## تطبیق ترتیب API خانه با صفحه اصلی یادمان سیستم

پیش‌فرض اختصاصی یادمان سیستم مطابق ترتیب فعلی صفحه اصلی بازطراحی شد:

1. اسلایدر بنر لپ‌تاپ و اسپیکر
2. منوی دسترسی سریع
3. پیشنهاد شگفت‌انگیز
4. دسته‌بندی‌های ویژه
5. جدیدترین محصولات
6. محصولات کامپیوتر و تجهیزات جانبی
7. بنرهای کامپیوتر و سخت‌افزار
8. محصولات لپ‌تاپ و لوازم جانبی
9. انواع اسپیکر
10. خرید بر اساس دسته‌بندی
11. محبوب‌ترین برندها
12. بنر ساعت هوشمند
13. سوالات متداول

## معماری عمومی و قابل استفاده روی فروشگاه‌های دیگر

موتور API خانه همچنان مستقل از قالب است. پیش‌فرض یادمان سیستم فقط زمانی فعال می‌شود که دامنه سایت `yademansystem.ir` باشد. فروشگاه‌های دیگر پیش‌فرض عمومی ووکامرس را دریافت می‌کنند و می‌توانند همان ساختار را از بخش «ووکامرس ← Application API» تنظیم کنند.

شناسه دسته‌بندی‌ها و برندها در پیش‌فرض یادمان سیستم هاردکد نشده‌اند. نام دسته یا برند در زمان اجرای API به شناسه واقعی همان سایت تبدیل می‌شود؛ بنابراین حذف و ایجاد دوباره termها باعث وابستگی به ID قدیمی نمی‌شود.

## انواع بخش‌های جدید

- `action_menu` برای آیکون‌های خدمات صفحه اصلی
- `promo_banners` برای بنرهای تبلیغاتی تکی یا چندستونه
- `brands` برای برندها همراه تصویر و action
- `faq` برای سوالات متداول

بخش‌های قبلی `banner_slider`، `menu`، `products`، `categories` و `custom` نیز حفظ شده‌اند.

## تصاویر دسته‌بندی و برند

تصویر دسته و برند با کیفیت اصلی دریافت می‌شود. برای برندها چندین کلید رایج متای افزونه‌های برند پشتیبانی شده و در صورت وجود متای سفارشی دارای نام image، thumbnail یا logo نیز بررسی می‌شود.

## سوالات متداول

بخش FAQ ابتدا محتوای برگه صفحه اصلی را بررسی می‌کند و آیتم‌های آکاردئون رایج Woodmart/WPBakery و عناصر HTML از نوع `details` را استخراج می‌کند. اگر ساختار صفحه قابل شناسایی نباشد، سوالات تنظیم‌شده در preset بازگردانده می‌شوند.

## مهاجرت تنظیمات قدیمی

اگر تنظیمات ذخیره‌شده دقیقاً همان ساختار پنج‌بخشی نسخه‌های قبلی باشد، در دامنه یادمان سیستم به‌صورت خودکار به preset کامل نسخه 2.0.4 ارتقا پیدا می‌کند. تنظیمات سفارشی دیگر فروشگاه‌ها بازنویسی نمی‌شوند.
