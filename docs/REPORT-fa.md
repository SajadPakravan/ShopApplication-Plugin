# گزارش تغییرات Application API نسخه 2.2.3

## نوع عمومی تصویر

نوع‌های قدیمی `banner` و `menu` در API خانه به نوع ثابت `image` تبدیل شدند. تنظیمات ذخیره‌شده قبلی هنگام خواندن به‌صورت خودکار مهاجرت می‌شوند و ترتیب، عنوان، زیرعنوان، تصویر و Component بخش‌ها حفظ می‌شود.

## ساختار آیتم تصویر

شناسه آیتم از تنظیمات و خروجی حذف شد. هر آیتم تصویر اکنون فقط شامل عنوان، زیرعنوان، تصویر و عملیات است:

```json
{
  "title": "",
  "subtitle": "",
  "image": "https://example.com/image.webp",
  "action": {
    "type": "category",
    "destination": 166
  }
}
```

عملیات بدون مقصد همیشه به‌صورت زیر برمی‌گردد:

```json
{
  "type": null,
  "destination": null
}
```

## مقصدهای قابل انتخاب

فقط مقصدهای زیر در تنظیمات تصویر وجود دارند:

- محصول: `product`
- دسته‌بندی: `category`
- برند: `brand`
- برچسب: `tag`
- لینک: `url`
- بدون عملیات: `null`

برای چهار نوع اول، مقصد به‌صورت شناسه عددی و برای لینک به‌صورت URL ذخیره می‌شود. عنوان فیلد مقصد بر اساس نوع انتخابی تغییر می‌کند و در حالت بدون عملیات، فیلد مقصد غیرفعال می‌شود.

## برند و دسته‌بندی

پارامتر `action` از آیتم‌های برند حذف شد. آیتم‌های دسته‌بندی نیز همچنان بدون `action` هستند و شناسه خود آیتم برای بازکردن صفحه مربوط استفاده می‌شود.

## سازگاری

منطق محصولات، فیلترها، `view_all`، ترتیب بخش‌ها، فعال یا غیرفعال‌کردن بخش‌ها و endpointهای قابل‌تنظیم تغییری نکرده است.
