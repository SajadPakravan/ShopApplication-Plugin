# گزارش تغییرات Application API نسخه 2.3.0

## تب محصولات و آدرس‌های ثابت API

تب «فروشگاه» به «محصولات» تغییر کرد و تب جداگانه «محصول» حذف شد. اطلاعات هر دو API در تب محصولات قرار دارد:

- فهرست محصولات: `/wp-json/app-api/v1/products`
- جزئیات محصول: `/wp-json/app-api/v1/products/{id}`

این دو endpoint ثابت هستند و دیگر فیلد قابل ویرایش ندارند. تب محصولات فقط راهنمای ساده پارامترهای درخواست، ساختار فیلترها و نمونه درخواست را به مدیر نمایش می‌دهد.

## بازطراحی filters و اضافه شدن filter_by

پاسخ API فهرست محصولات اکنون دارای فیلترهای واقعی قابل استفاده است:

- دسته‌بندی‌های محصولات به صورت درختی و همراه با `children`؛ ترتیب دسته‌ها از ترتیب ذخیره‌شده ووکامرس پیروی می‌کند.
- برندها به ترتیب حروف الفبا.
- ویژگی‌های سراسری ووکامرس فقط در صورتی که «بایگانی فعال شود؟» برای آن‌ها فعال باشد.
- گزینه‌های ویژگی و کد رنگ در صورت موجود بودن اطلاعات رنگ.

`filter_by` فقط وضعیت فیلترهای اعمال‌شده به درخواست جاری را نگه می‌دارد و `brand_taxonomy` از پاسخ حذف شده است.

## اصلاح محصولات متغیر تخفیف‌دار

فیلتر `on_sale` در مخزن محصولات علاوه بر ردیف والد، متغیرهای منتشرشده محصول را نیز بررسی می‌کند. بنابراین اگر فقط یکی از متغیرها تخفیف داشته باشد، والد آن محصول در بخش پیشنهاد شگفت‌انگیز و سایر لیست‌های تخفیف‌دار حذف نمی‌شود. منطق قبلی انتخاب متغیر دارای بیشترین درصد تخفیف برای کارت محصول حفظ شده است.

## فعال/غیرفعال کردن مشاهده همه

برای بخش‌های محصولات، دسته‌بندی، برند و نوشته‌ها گزینه «فعال کردن مشاهده همه» اضافه شد. با خاموش کردن آن:

- تنظیمات مشاهده همه در پنل مخفی می‌شود.
- تنظیمات قبلی آن حفظ می‌شود.
- خروجی API دقیقاً `"view_all": {}` خواهد بود.

## اصلاح برندها

- `parent` از آیتم برند حذف شد.
- `count` با شمارش محصولات والد منتشرشده محاسبه می‌شود و به شمارنده احتمالی قدیمی taxonomy وابسته نیست.
- تصویر برند از API رسمی برندهای ووکامرس و چند ساختار رایج term meta خوانده می‌شود و تصویر اصلی/full برگردانده می‌شود.

## نوع جدید نوشته‌ها

در «افزودن بخش جدید» نوع «نوشته‌ها» با مقدار JSON ثابت `posts` اضافه شد. مدیر می‌تواند:

- شناسه دلخواه بخش
- عنوان و زیرعنوان
- جهت، سطر و ستون
- تعداد نمایش
- شناسه یک یا چند دسته‌بندی نوشته
- مشاهده همه

را تنظیم کند. لیست نوشته‌ها از نوشته‌های منتشرشده و از جدیدترین به قدیمی‌ترین ساخته می‌شود. مقصد مشاهده همه در این نوع فقط «دسته‌بندی»، «لینک» یا «بدون عملیات» است.

## تغییر برچسب‌های شناسه

تمام متن‌های «ID» و «آیدی» در رابط تنظیمات بخش‌های صفحه خانه با «شناسه» جایگزین شدند.

## کش API خانه

تنظیم کش از پنل مدیریت حذف شد. زمان کش اکنون به شکل داخلی و ثابت ۶۰ ثانیه است. تغییرات مرتبط با محصولات، متغیرها، taxonomyها، نوشته‌ها و تنظیمات خانه نسخه کش را افزایش می‌دهند تا پاسخ تازه دوباره ساخته شود.

## منوی مستقل مدیریت

Application API دیگر زیرمنوی ووکامرس نیست. یک منوی مستقل در مدیریت وردپرس نزدیک بخش محصولات ایجاد می‌شود و فقط کاربرانی که capability مدیریتی `manage_options` دارند به آن دسترسی دارند.
