# گزارش تغییرات Application API نسخه 2.2.0

## هدف نسخه

API خانه از مجموعه‌ای از بخش‌های از پیش تعریف‌شده به یک صفحه‌ساز بصری و پویا تبدیل شد. مدیر فروشگاه می‌تواند بدون نوشتن JSON، بخش جدید بسازد، نوع آن را تعیین کند، آن را حذف یا غیرفعال کند و ترتیب خروجی را تغییر دهد.

## انواع بخش‌های قابل افزودن

- بنر (`banner`)
- محصولات (`products`)
- دسته‌بندی‌ها (`categories`)
- برندها (`brands`)

بخش منوی دسترسی سریع موجود نیز با نوع `menu` حفظ شده است تا تنظیمات و آیکون‌های قبلی فروشگاه از بین نروند.

## بخش بنر یکپارچه

نوع‌های قدیمی اسلایدر، بنرهای تبلیغاتی و بنر تکی در یک نوع واحد با نام `banner` ادغام شدند. هر بخش بنر می‌تواند یک یا چند آیتم داشته باشد و مدیر می‌تواند تعداد سطر و ستون، Component و ترتیب آیتم‌ها را تعیین کند.

نمونه‌های قابل ساخت با همین نوع:

- اسلایدر اصلی با Component برابر `banner_slider`
- دو بنر کنار هم با `rows=1` و `columns=2`
- چهار بنر شبکه‌ای با `rows=2` و `columns=2`
- بنر تکی با سطر و ستون خالی

## بخش محصولات عمومی

هر بخش محصولات اکنون می‌تواند هم‌زمان این تنظیمات را داشته باشد:

- چند ID دسته‌بندی
- چند ID برند
- فقط محصولات تخفیف‌دار
- تعداد محصولات (`per_page`) با پیش‌فرض ۱۰
- تعداد سطر برای نمایش چندردیفه
- عنوان اسلاید پایانی «مشاهده همه»

اگر هیچ دسته یا برندی تعیین نشود، جدیدترین محصولات کل فروشگاه نمایش داده می‌شوند. اگر دسته و برند هر دو تعیین شوند، محصول باید با هر دو گروه فیلتر سازگار باشد.

در `view_all.action` همه فیلترهای واقعی همان بخش برگردانده می‌شوند تا Flutter بتواند صفحه «نمایش همه» را دقیقاً با همان شرایط باز کند.

## دسته‌بندی‌ها و برندها

برای این دو نوع فقط IDهای دقیق واردشده نمایش داده می‌شوند و ترتیب ورود IDها حفظ می‌شود. گزینه «عدم نمایش موارد خالی» حذف شد و حتی دسته یا برند بدون محصول نیز در صورت انتخاب مدیر برگردانده می‌شود.

## مدیریت بصری

- ساخت بخش جدید از طریق انتخاب نوع
- ID دلخواه و قابل ویرایش برای هر بخش
- Component دلخواه و قابل ویرایش
- عنوان و زیرعنوان مستقل
- فعال یا غیرفعال‌سازی
- حذف کامل بخش
- مرتب‌سازی با Drag & Drop یا دکمه بالا و پایین
- افزودن، حذف و مرتب‌سازی آیتم‌های بنر
- انتخاب تصویر اصلی از Media Library
- طراحی واکنش‌گرا برای نمایشگرهای کوچک

## سازگاری

تنظیمات نسخه‌های قبلی هنگام خواندن به ساختار جدید تبدیل می‌شوند:

- `banner_slider` و `promo_banners` به `banner`
- `action_menu` به `menu`
- منابع ثابت محصول به فیلترهای عمومی دسته، برند و تخفیف

API محصولات و API جزئیات محصول این نسخه تغییری نکرده‌اند.
