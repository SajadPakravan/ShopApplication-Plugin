# گزارش تغییرات Application API نسخه 2.0.5

## قرارداد جدید API خانه

مسیر:

`GET /wp-json/app-api/v1/home`

در آبجکت هر بخش، فیلد عمومی `id` حذف شد. شناسه‌های داخلی فقط در تنظیمات سمت سرور باقی می‌مانند و در پاسخ REST دیده نمی‌شوند. اپلیکیشن نوع ویجت را از `type` انتخاب می‌کند و ترتیب آرایه `sections` ترتیب نمایش است.

فیلد `layout` از تمام بخش‌ها و فیلد `meta` از تمام بخش‌های محصول حذف شد. اطلاعات صفحه‌بندی و کوئری داخلی دیگر وارد JSON صفحه خانه نمی‌شود.

## بنرها

فیلدهای `title` و `subtitle` از آیتم‌های بنر حذف شدند. هر بنر فقط اطلاعات عملی لازم مانند تصویر اصلی و action را برمی‌گرداند.

## منوی دسترسی سریع

نام و تصویر آیتم‌ها با منوی فعلی صفحه اصلی یادمان سیستم هماهنگ شد:

- اپلیکیشن فروشگاه
- حراجی
- مشاوره خرید
- سفارش اجناس
- سفارش مونتاژ
- سفارش تعمیرات
- درخواست مرجوعی
- پرداخت فروشگاه
- نظرسنجی فروشگاه
- بیشتر

## بخش‌های محصول

هر بخش محصول همیشه از صفحه اول استفاده می‌کند و مرتب‌سازی آن همیشه `date desc` است. ورودی‌های عمومی جست‌وجو، نوع، برند، برچسب، قیمت و order سفارشی در تنظیمات قدیمی صفحه خانه نادیده گرفته می‌شوند.

تنها مقدار عمومی قابل تنظیم برای هر بخش محصول `per_page` است. مقدار پیش‌فرض 10 و سقف ایمن هر بخش 30 محصول است.

منبع‌های ثابت:

- `on_sale`: محصولات تخفیف‌دار، جدیدترین به قدیمی‌ترین؛
- `latest`: همه محصولات منتشرشده، جدیدترین به قدیمی‌ترین؛
- `category`: محصولات دسته‌های تعیین‌شده، جدیدترین به قدیمی‌ترین.

بخش پیشنهاد شگفت‌انگیز به‌طور ثابت از `on_sale` استفاده می‌کند و دارای فیلد مستقل `view_all` است. اپلیکیشن باید `view_all` را بعد از آخرین محصول به‌عنوان آخرین اسلاید نمایش دهد. این آیتم داخل آرایه محصولات قرار نگرفته تا ساختار کارت‌های محصول یکدست بماند.

## دسته‌بندی‌ها و برندهای انتخابی

برای بخش «دسته‌بندی‌های ویژه»، «خرید بر اساس دسته‌بندی» و «محبوب‌ترین برندها» می‌توان شناسه‌های دقیق را در `config.include` وارد کرد:

```json
{"type":"categories","config":{"include":[55,166,167]}}
```

```json
{"type":"brands","config":{"include":[313,362,367]}}
```

اگر `include` دارای ID باشد، فقط همان IDها و با همان ترتیب برگردانده می‌شوند. نام‌ها و slugهای قدیمی فقط وقتی استفاده می‌شوند که `include` خالی باشد.

## سوالات متداول

بخش FAQ از preset صفحه خانه حذف شد. حتی اگر در تنظیمات قدیمی باقی مانده باشد، HomeBuilder آن را به پاسخ API خانه اضافه نمی‌کند.

## مهاجرت

تنظیمات قدیمی پنج‌بخشی و presetهای مدیریت‌شده نسخه‌های قبل روی دامنه یادمان سیستم به preset نسخه 2.0.5 ارتقا پیدا می‌کنند و نسخه کش صفحه خانه نیز تغییر می‌کند.
