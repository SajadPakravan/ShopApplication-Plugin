# گزارش تغییرات Application API 2.3.1

## تغییرات API خانه

- اگر «مشاهده همه» یک بخش غیرفعال باشد، کلید `view_all` به‌طور کامل از JSON همان بخش حذف می‌شود.
- نوع مقصد مشاهده همه برای هر نوع بخش محدود و ثابت شد:
  - محصولات: همه محصولات، دسته‌بندی، برند
  - دسته‌بندی: همه دسته‌بندی‌ها
  - برند: همه برندها
  - نوشته‌ها: همه نوشته‌ها، دسته‌بندی
- گزینه «بدون عملیات» از Action آیتم‌های تصویر و مشاهده همه حذف شد.
- نوع `all` اضافه شد. در این حالت `destination_id` و `url` برابر `null` هستند.
- اگر در مقصد دسته‌بندی یا برند شناسه خالی باشد، مفهوم آن همه دسته‌بندی‌ها یا همه برندهاست. در نوشته‌ها نیز دسته‌بندی بدون شناسه یعنی همه دسته‌بندی‌های نوشته.
- کلید `on_sale` از Action مشاهده همه بخش نوشته‌ها حذف شد.
- تاریخ نوشته‌ها فقط با قالب تاریخ `YYYY-MM-DD` برگردانده می‌شود و ساعت حذف شد.

## انتخاب دسته‌بندی در بخش دسته‌بندی خانه

دو روش انتخاب وجود دارد:

1. وارد کردن سفارشی شناسه دسته‌بندی‌ها با ترتیب دلخواه.
2. انتخاب یک دسته‌بندی والد از بین دسته‌بندی‌های اصلی؛ در این حالت زیر‌دسته‌های مستقیم همان والد با ترتیب فروشگاه در API قرار می‌گیرند.

## فیلترهای API محصولات

- `on_sale` به `filter_by` اضافه شد و از URL قابل تنظیم است.
- مقدار پیش‌فرض `on_sale` در `filter_by` برابر `null` است.
- در `filters.attribute`، کلیدهای اضافی `slug`، `value` و `color` حذف شدند.
- هر ویژگی فقط `id`، `name` و `options` دارد و هر option فقط `id` و `name` دارد.

## تصویر برندها

حل‌کننده تصویر برند گسترده‌تر شد و علاوه بر روش استاندارد WooCommerce Brands، کلیدهای رایج term meta، داده‌های سریال‌شده/تو‌در‌تو و ساختارهای option قدیمی افزونه‌های برند را بررسی می‌کند و تصویر اصلی رسانه را برمی‌گرداند.

## سازگاری

- Endpointهای قبلی بدون تغییر باقی مانده‌اند.
- منطق قیمت، تخفیف محصولات متغیر، انتخاب variation مناسب و مرتب‌سازی موجود/ناموجود دست‌نخورده است.
