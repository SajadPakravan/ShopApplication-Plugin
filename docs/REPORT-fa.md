# گزارش تغییرات Application API 2.4.0

## کارت محصول یکپارچه

ساختار کارت محصول در API خانه، API لیست محصولات و بخش محصولات مرتبط یکسان شد. فیلدهای کارت شامل شناسه، نام، قیمت، قیمت اصلی، درصد تخفیف، موجودی، تصویر، نام متغیر منتخب، تعداد فروش، امتیاز میانگین، دسته‌بندی‌ها، برند و رنگ‌های محصول متغیر است.

- `average_rating` همیشه رشته با یک رقم اعشار است؛ مانند `"3.5"`.
- هر دسته‌بندی شامل `id`، `name` و تصویر اصلی دسته‌بندی است.
- برند به‌صورت یک آبجکت تکی شامل `id`، `name` و `image` برگردانده می‌شود.
- `colors` فقط کدهای رنگ قابل تشخیص برای ویژگی‌های متغیر محصول را برمی‌گرداند و در صورت نبود رنگ آرایه خالی است.

## اصلاح مرتب‌سازی فروش

نام صحیح مرتب‌سازی تعداد فروش `count_sales` است. نام اشتباه قبلی دیگر در قرارداد عمومی API نمایش داده نمی‌شود. فقط برای مهاجرت تنظیمات قدیمی، تبدیل داخلی مقدار قبلی حفظ شده است.

## نوشته‌های صفحه خانه

بعد از تاریخ شمسی هر نوشته، لیست دسته‌بندی‌های همان نوشته با `id` و `name` اضافه شد.

## API جزئیات محصول

- `sku` بلافاصله بعد از `id` قرار گرفت.
- `description` بلافاصله بعد از `name` قرار گرفت.
- `average_rating` به رشته یک‌رقم اعشار تبدیل شد.
- `categories` شامل تصویر دسته‌بندی است.
- `brand` به‌صورت یک آبجکت تکی همراه تصویر برند برگردانده می‌شود.
- `default_variation` فقط شناسه عددی variation پیش‌فرض است.
- `variations` به تفکیک ویژگی‌های متغیر گروه‌بندی می‌شود.
- هر option ویژگی متغیر شامل شناسه variation، نام همان گزینه، SKU، رنگ، تصویر گزینه، قیمت، قیمت اصلی، درصد تخفیف، موجودی و تصویر واقعی محصول variation است.

## بخش‌های قابل تنظیم جزئیات محصول

در تب محصولات، دو زیرتب «لیست محصولات» و «جزئیات محصول» ایجاد شد. بخش جزئیات محصول دو بخش از پیش ساخته‌شده دارد:

1. محصولات مرتبط
2. نظرات کاربران

هر دو بخش قابلیت فعال/غیرفعال‌سازی و تغییر ترتیب دارند و مانند تنظیمات Home به‌صورت آکاردئونی مدیریت می‌شوند.

محصولات مرتبط از دسته‌بندی‌های خود محصول جاری انتخاب می‌شوند و مدیر امکان تغییر منبع به دسته‌بندی یا برند دلخواه ندارد. تعداد نمایش، عنوان، زیرعنوان، چیدمان، فقط تخفیف‌دار و مشاهده همه قابل تنظیم است.

برای نظرات کاربران نیز تعداد نمایش، عنوان، زیرعنوان، چیدمان و مشاهده همه قابل تنظیم است. مرتب‌سازی مشاهده همه نظرات بین تاریخ و امتیاز و ترتیب صعودی/نزولی قابل انتخاب است.
