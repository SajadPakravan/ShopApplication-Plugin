# گزارش تغییرات Application API 2.6.3

## نمایش اختیاری زیر‌دسته‌ها در انتخاب سفارشی
- در بخش‌های `category` صفحه خانه، وقتی روش انتخاب روی «انتخاب سفارشی با شناسه» باشد، گزینه «زیر‌دسته‌های دسته‌بندی‌های مشخص‌شده نیز نمایش داده شوند» اضافه شده است.
- اگر گزینه غیرفعال باشد، هر دسته انتخابی همیشه `children: []` دارد.
- اگر گزینه فعال باشد، فرزندان و نسل‌های بعدی هر دسته انتخابی به‌صورت بازگشتی داخل `children` قرار می‌گیرند.
- این تنظیم فقط برای روش سفارشی نمایش داده می‌شود و هنگام تغییر روش انتخاب مخفی و غیرفعال می‌شود.

## صفحه دسته‌بندی‌ها
- همین گزینه برای بخش `category` در API صفحه دسته‌بندی‌ها نیز اضافه شده است.
- همه آیتم‌های دسته‌بندی در API صفحه دسته‌بندی‌ها اکنون همیشه پارامتر `children` دارند.
- در حالت «نمایش دسته‌بندی‌های اصلی و والد» و «نمایش زیر‌دسته‌های یک دسته‌بندی خاص»، `children` برای آیتم‌های لیست خالی است تا رفتار این دو حالت با حالت درختی تداخل نداشته باشد.
- در حالت «نمایش همه دسته‌بندی‌های والد با همه زیر‌دسته‌ها»، ساختار درختی کامل مانند قبل برگردانده می‌شود.
- در حالت «نمایش دسته‌بندی‌های دلخواه»، مقدار `children` بر اساس چک‌باکس جدید کنترل می‌شود.

## سازگاری
- تنظیمات نسخه‌های قبلی بدون تغییر قابل استفاده‌اند و مقدار پیش‌فرض گزینه جدید `false` است.
- ساختار پایه هر دسته‌بندی همچنان شامل `id`، `name`، `count`، `image` و `children` است.
