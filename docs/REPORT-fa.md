# Shop Application 3.1.0

این نسخه معماری وب‌سرویس‌های حساب کاربری را از API جزئیات مشتری جدا می‌کند.

## API مشخصات مشتری

- `GET /wp-json/app-api/v1/customers/{id}` فقط مشخصات شخصی، اطلاعات تماس، آدرس‌ها و شمارنده‌های حساب را برمی‌گرداند.
- `PATCH|PUT /wp-json/app-api/v1/customers/{id}` برای ویرایش مشخصات همان مشتری است.
- لیست‌های سفارش، سبد خرید، علاقه‌مندی، محصولات مشاهده‌شده و نظرات دیگر داخل این پاسخ قرار نمی‌گیرند.

شمارنده‌های حساب: `orders_count`, `cart_count`, `favorites_count`, `viewed_products_count`, `comments_count`.

## وب‌سرویس‌های مستقل حساب

- `/orders`: GET و POST؛ ویرایش سفارش با PATCH/PUT روی `/orders/{id}`.
- `/cart`: GET، POST، PATCH/PUT و DELETE.
- `/favorites`: GET، POST، PATCH/PUT و DELETE.
- `/viewed-products`: فقط GET.
- `/comments`: GET و POST؛ ویرایش/حذف با `/comments/{id}`.

تمام این وب‌سرویس‌ها کاربر را از Bearer Token تشخیص می‌دهند و شناسه مشتری در URL آن‌ها لازم نیست.

## علاقه‌مندی‌ها

Adapter برای Wishlist فعال فروشگاه اضافه شد. WoodMart در اولویت است، YITH نیز پشتیبانی می‌شود و برای سایت‌های بدون Provider شناخته‌شده fallback داخلی وجود دارد.

## محصولات مشاهده‌شده

بازدید محصول برای کاربر واردشده هم در صفحه محصول وب‌سایت و هم هنگام دریافت API جزئیات محصول ثبت می‌شود. لیست از `/viewed-products` خوانده می‌شود.

## پنل مدیریت

کارت‌های وب‌سرویس‌ها عمودی و ریسپانسیو شدند. در «وب‌سرویس‌های حساب کاربری» کارت‌های جدا برای مشخصات مشتری، سفارشات، سبد خرید، علاقه‌مندی‌ها، محصولات مشاهده‌شده و نظرات ایجاد شد.
