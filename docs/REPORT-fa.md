# گزارش تغییرات Application API 2.6.2

## یکسان‌سازی ساختار دسته‌بندی‌ها در API خانه
- پارامتر `parent` از آیتم‌های بخش دسته‌بندی صفحه خانه حذف شد.
- هر دسته‌بندی اکنون همیشه پارامتر `children` دارد.
- اگر دسته‌بندی فرزندی نداشته باشد، مقدار `children` برابر آرایه خالی است.
- اگر دسته‌بندی زیر‌دسته داشته باشد، زیر‌دسته‌ها به‌صورت بازگشتی و با همان ساختار `id`, `name`, `count`, `image`, `children` برگردانده می‌شوند.
- ترتیب زیر‌دسته‌ها مطابق ترتیب فروشگاه حفظ می‌شود و تصویر دسته‌بندی همچنان از فایل اصلی/کامل taxonomy گرفته می‌شود.
- مقدار `count` بر اساس تعداد محصولات منتشرشده هر دسته‌بندی ساخته می‌شود.
