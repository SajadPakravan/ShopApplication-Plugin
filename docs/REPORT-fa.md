# گزارش تغییرات Application API 2.5.0

## اصلاح ساختار API جزئیات محصول

ساختار عمومی جزئیات محصول با الگوی فایل نمونه کاربر هماهنگ شد. دیگر برای «نظرات کاربران» و «محصولات مرتبط» از آرایه `sections` استفاده نمی‌شود. بعد از آخرین فیلد اصلی محصول یعنی `variations`، در صورت فعال بودن، ابتدا `reviews` و سپس `related_products` قرار می‌گیرد.

ساختار هرکدام همچنان شامل `data` و در صورت فعال بودن، `view_all` است. غیرفعال کردن یک بخش باعث حذف کامل همان کلید از JSON می‌شود.

در پنل **Application API → محصولات → جزئیات محصول** امکان فعال/غیرفعال‌سازی، عنوان، زیرعنوان، چیدمان، تعداد نمایش، تنظیمات مشاهده همه و سایر تنظیمات قبلی حفظ شده است؛ اما جابه‌جایی و تنظیم ترتیب این دو بخش حذف شده و ترتیب خروجی ثابت است: نظرات، سپس محصولات مرتبط.

## API جدید صفحه دسته‌بندی

Endpoint ثابت زیر اضافه شد:

`GET /wp-json/app-api/v1/categories/{id}`

پاسخ شامل شناسه، نام، تعداد محصولات منتشرشده، تصویر اصلی دسته‌بندی جاری و آرایه `sections` است.

در تب **دسته‌بندی‌ها** یک صفحه‌ساز بصری مانند صفحه خانه ایجاد شده است. مدیر سایت می‌تواند بخش‌ها را فعال یا غیرفعال کند، با Drag & Drop یا دکمه‌های بالا/پایین ترتیب آن‌ها را تغییر دهد، بخش جدید اضافه یا حذف کند و تنظیمات هر بخش را جداگانه مدیریت کند.

انواع بخش قابل افزودن:

1. **تصویر (`image`)**: ساختار همان بخش تصویر صفحه خانه را دارد و برای اسلایدر بنر، بنر عادی، منوی تصویری و کاربردهای مشابه قابل استفاده است.
2. **محصول (`product`)**: یک محصول منتشرشده مشخص با وارد کردن شناسه محصول انتخاب می‌شود و با قرارداد مشترک کارت محصول برگردانده می‌شود.
3. **دسته‌بندی (`category`)**: لیست دسته‌بندی‌های محصول را برمی‌گرداند.

## روش انتخاب دسته‌بندی‌ها

برای بخش نوع دسته‌بندی دو روش وجود دارد:

- **انتخاب سفارشی**: مدیر یک یا چند دسته‌بندی را مستقیماً از فهرست دسته‌بندی‌های فروشگاه انتخاب می‌کند و فقط همان موارد برگردانده می‌شوند.
- **نمایش دسته‌بندی‌های والد**: همه دسته‌بندی‌های سطح اصلی (`parent = 0`) با ترتیب تعریف‌شده در فروشگاه برگردانده می‌شوند.

هر دسته‌بندی در `data` شامل این فیلدها است:

- `id`
- `name`
- `count`: تعداد محصولات منتشرشده آن دسته
- `image`: لینک تصویر اصلی/Full دسته‌بندی

## کنترل کیفیت

تمام فایل‌های PHP با `php -l` بررسی شدند، JavaScript پنل با `node --check` بررسی شد و فایل ZIP نهایی نیز با تست داخلی ZIP کنترل شد.
