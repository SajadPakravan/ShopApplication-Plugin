# گزارش تغییرات Application API 2.6.0

- مسیر جدید `GET /wp-json/app-api/v1/categories` برای صفحه عمومی دسته‌بندی‌ها اضافه شد.
- تب «دسته‌بندی‌ها» در مدیریت به دو زیرتب «صفحه دسته‌بندی‌ها» و «جزئیات دسته‌بندی» تقسیم شد.
- صفحه دسته‌بندی‌ها اکنون صفحه‌ساز مستقل با بخش‌های تصویر، محصول تکی و دسته‌بندی دارد.
- تنظیمات صفحه‌ساز قبلی دسته‌بندی بدون حذف اطلاعات، به صفحه عمومی `/categories` اختصاص پیدا می‌کند.
- بخش دسته‌بندی چهار روش منبع دارد: دسته‌های اصلی، زیر‌دسته‌های یک دسته مشخص، شناسه‌های دلخواه، و درخت کامل والد/زیر‌دسته.
- در حالت «زیر‌دسته‌های یک دسته مشخص» می‌توان هر دسته محصول را به‌عنوان مبنا انتخاب کرد، نه فقط دسته‌های سطح اصلی.
- حالت درخت کامل، دسته‌های والد را همراه همه فرزندان در آرایه‌های تو‌در‌توی `children` برمی‌گرداند.
- هر آیتم دسته‌بندی دارای شناسه، نام، تعداد محصولات منتشرشده و تصویر اصلی/کامل دسته است.
- `GET /categories/{id}` دیگر بخش‌های صفحه‌ساز ندارد و فقط جزئیات ثابت همان دسته را برمی‌گرداند.
- جزئیات دسته شامل نام، توضیحات، تصویر اصلی، تعداد محصولات، مسیر والدها و همه زیر‌دسته‌ها به‌صورت درختی است.
- مسیر والدها از بالاترین دسته تا والد مستقیم مرتب می‌شود.
- نسخه افزونه به 2.6.0 ارتقا یافت.
