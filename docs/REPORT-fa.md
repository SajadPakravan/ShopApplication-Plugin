# گزارش تغییرات Application API نسخه 2.6.4

## API جزئیات دسته‌بندی

مسیر ثابت زیر توسعه داده شد:

`GET /wp-json/app-api/v1/categories/{id}`

ساختار جزئیات دسته‌بندی اکنون به ترتیب ثابت شامل اطلاعات خود دسته‌بندی، مسیر والدها، زیر‌دسته‌های مستقیم، محصولات دسته‌بندی و برندهای موجود در محصولات همان دسته‌بندی است.

### زیر‌دسته‌ها

- فقط فرزندان مستقیم دسته‌بندی انتخاب‌شده برگردانده می‌شوند.
- ترتیب تعریف‌شده دسته‌بندی‌های فروشگاه حفظ می‌شود.
- هر آیتم دارای `id`، `name`، `count`، `image` و `children` است.
- چون در API جزئیات دسته‌بندی فقط فرزندان مستقیم خواسته شده‌اند، مقدار `children` هر فرزند در این لیست `[]` است.

### محصولات دسته‌بندی

- بعد از `children` و قبل از برندها قرار می‌گیرد.
- از همان قرارداد کارت محصول مشترک پلاگین استفاده می‌کند.
- مرتب‌سازی اولیه بر اساس جدیدترین محصولات است و وضعیت موجودی همچنان توسط منطق اصلی ProductRepository مدیریت می‌شود.
- تعداد نمایش از تنظیمات قابل تعیین است.
- مشاهده همه قابل فعال/غیرفعال کردن است.
- مقصد مشاهده همه به‌صورت خودکار همان دسته‌بندی فعلی است.

### برندهای دسته‌بندی

- بعد از محصولات قرار می‌گیرد.
- فقط برندهایی نمایش داده می‌شوند که حداقل یک محصول منتشرشده در دسته‌بندی فعلی دارند.
- هر برند دقیقاً قرارداد بخش برند Home را دارد: `id`، `name`، `count` و `image`.
- `count` تعداد محصولات همان برند در دسته‌بندی فعلی است، نه شمارش کلی برند در کل فروشگاه.
- برندها به ترتیب نام مرتب می‌شوند.
- تعداد نمایش و مشاهده همه قابل تنظیم است.

## تنظیمات جزئیات دسته‌بندی

در تب «دسته‌بندی‌ها ← جزئیات دسته‌بندی» دو بخش ثابت اضافه شد:

1. محصولات دسته‌بندی
2. برندهای دسته‌بندی

این دو بخش قابلیت جابه‌جایی ندارند و ترتیبشان ثابت است. برای هر بخش فقط موارد زیر تنظیم می‌شود:

- فعال/غیرفعال بودن
- تعداد نمایش
- فعال/غیرفعال کردن مشاهده همه
- عنوان دکمه مشاهده همه

هیچ تنظیمی برای جهت نمایش، تعداد سطر یا تعداد ستون وجود ندارد.

## تنظیمات جزئیات محصول

قسمت «چیدمان خروجی» از دو بخش «نظرات کاربران» و «محصولات مرتبط» حذف شد. تنظیمات فعال‌سازی، تعداد نمایش، محصولات تخفیف‌دار در بخش مرتبط و مشاهده همه حفظ شده‌اند.

## نسخه

نسخه پلاگین از 2.6.3 به 2.6.4 افزایش یافت.
