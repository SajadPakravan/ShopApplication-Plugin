# گزارش تغییرات Application API نسخه 2.2.5

## حذف Component

فیلد `component` از صفحه تنظیمات، داده ذخیره‌شده و خروجی JSON صفحه خانه حذف شد. چیدمان هر بخش اکنون فقط با سه مقدار ثابت مدیریت می‌شود:

```json
"layout": {
  "direction": "horizontal",
  "rows": 1,
  "columns": 1
}
```

تنظیمات قدیمی که دارای `component` هستند همچنان قابل خواندن‌اند، اما این مقدار نادیده گرفته می‌شود و دیگر در پاسخ API برنمی‌گردد.

## ساده‌سازی متن‌های پنل

- معادل انگلیسی گزینه‌های مرتب‌سازی و ترتیب از رابط مدیریت حذف شد؛ مقدار انگلیسی استاندارد همچنان در JSON ذخیره و ارسال می‌شود.
- متن توضیحی مربوط به `action.title` حذف شد.
- توضیح زیر عنوان «تنظیمات بخش‌های صفحه خانه» حذف شد.
- برچسب متنی Drag & Drop از کارت فعال‌سازی و ترتیب نمایش حذف شد.

## آکاردئون حرفه‌ای تنظیمات

کارت فعال‌سازی و ترتیب نمایش و تمام کارت‌های تنظیمات بخش‌ها به یک آکاردئون هماهنگ تبدیل شدند. با باز کردن هر کارت، کارت باز قبلی با انیمیشن نرم بسته می‌شود. این رفتار بین کارت ترتیب نمایش و کارت‌های بخش‌ها نیز اعمال می‌شود تا صفحه مدیریت شلوغ نشود.

## نوار ذخیره تنظیمات

نوار ذخیره از حالت تمام‌عرض و چسبیده به لبه‌های صفحه خارج شد. اکنون داخل محدوده تنظیمات قرار می‌گیرد، از دو طرف فاصله دارد و به‌صورت واکنش‌گرا در نمایشگرهای کوچک تنظیم می‌شود تا با دکمه‌های شناور افزونه‌های دیگر تداخل کمتری داشته باشد.

## اصلاح جانبی

کلید تکراری `image` در سازنده آیتم‌های تصویری حذف شد. این اصلاح تغییری در قرارداد JSON ایجاد نمی‌کند و فقط از تعریف تکراری داخلی جلوگیری می‌کند.
